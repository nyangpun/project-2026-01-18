# 알려진 한계

일부러 이번 범위에서 빼둔 것들이에요. 나중에 README에 정리할 예정이에요.

## 이메일 인증
- 미인증 계정은 비밀번호가 틀려도 "이메일 인증이 필요합니다"가 나와요. Spring Security가 비밀번호보다 계정 상태를 먼저 확인해서, 미인증으로 가입된 이메일인지 알아낼 수 있어요. 비밀번호 확인 뒤에 검사하도록 바꾸면 막을 수 있는데 이번엔 넣지 않았어요.
- 인증 메일 재발송(POST /member/verify/resend)에 횟수 제한이 없어요. 인프라 단계에서 다룰 예정이에요.

## Redis
- Redis가 죽어 있으면 로그인 상태에서 검색어가 있는 검색이 약 4초 걸려요. 저장과 조회가 각각 2초 타임아웃을 기다려요. 검색 자체는 정상적으로 되고, 최근 검색어만 비어요.
